# 遗迹学徒：符文迷踪

一款纯前端 Canvas 小游戏，入口为 `index.html`，无需构建、无第三方依赖。

## 运行

直接双击 `index.html` 即可离线游玩；也可以启动本地静态服务器：

```bash
python -m http.server 8123
```

然后访问 http://localhost:8123/

## 操作

| 按键 | 功能 |
| --- | --- |
| 方向键 | 移动 |
| 空格 | 冲刺（消耗魔力） |
| F | 开关提灯（开灯视野更大，但持续消耗魔力） |
| Q | 释放冰霜新星（消耗雪花符文充能） |
| M | 静音 / 恢复音效 |
| R | 游戏结束后重新开始 |

## 内容

- 四个递进关卡：古堡外围、迷雾森林、古堡大厅、魔王之厅
- 符文收集、连击回蓝、高收益金符、雪花符文、荆棘陷阱与篝火
- 石像鬼巡逻、暗影幽魂追踪、不可击杀的魔王
- 关卡之间三选一的肉鸽天赋
- Web Audio 实时合成的脚步声、风声与蝉鸣
- 最终关传送门限时逃脱与 True Ending 结算

## 文件说明

- `index.html`：页面结构、HUD 与封面
- `styles.css`：界面样式、HUD 与结算动画
- `app.js`：关卡逻辑、Canvas 渲染与 Web Audio 音效
